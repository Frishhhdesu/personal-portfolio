# John Irish Fermin — Portfolio

A responsive personal portfolio built with React, Vite, Bootstrap, and custom CSS.

## Quick start on Windows

Double-click `start-portfolio.cmd`. It installs dependencies when needed, starts the local server, and opens the site in your browser.

## Run from a terminal

```bash
npm install
npm start
```

The site opens at `http://127.0.0.1:5173`. Keep the terminal window open while viewing the site. Press `Ctrl+C` in the terminal to stop it.

This is a Vite project, so opening `index.html` directly from File Explorer will not work. It must be served with `npm start` or `npm run dev`.

Node.js `20.19+` or `22.12+` is required. Check your version with `node --version`.

## Production build

```bash
npm run build
npm run preview
```

The optimized site is generated in `dist/`.

## Updating projects

Project placeholders are stored in `src/App.jsx` under `projectSlots`. Replace them with real project details and images when the case studies are ready.
